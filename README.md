**# Match Queens

A full-stack mentoring platform developed as part of the **QueenB × AppsFlyer Software Engineering Bootcamp** (August–September 2026).

The project supports mentoring workflows by connecting mentors and mentees and managing meeting requests and scheduling.

## My contribution

I contributed to the scheduling and backend workflows as part of a software engineering team, including:

- Meeting request and scheduling flows
- Request status management and duplicate-request handling
- HTTP-based API integration
- Database-related integration work

This repository is intended to showcase my work on the team project. Individual contributions and code history should be reviewed against the final uploaded source before making more specific claims.

## Tech stack

- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL, Prisma
- **API:** REST / HTTP
- **Frontend:** React (in the team application's starter stack)
- **Collaboration:** Git

## Features

- Mentor discovery and mentoring workflows
- Meeting requests and scheduling
- Request status tracking
